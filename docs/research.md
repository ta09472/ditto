# 리서치 노트 (2026-07-18, Sonnet 5 웹 리서치)

## 1. CCD 캠코더/디지캠 화질 특성 (Ditto 필터 근거)

우선순위순: ①저해상도+소프트렌즈 ②크로마 서브샘플링(4:1:1) 색번짐 — Cb/Cr만 가로 블러
③WB 편향 색캐스트(섀도우 시안/틸, 하이라이트 웜) ④좁은 DR — 하이라이트 급클립+블랙 리프트
⑤CCD 노이즈 — 루마 지배적, 어두울수록 강함, 컬러 스페클 20-30%
⑥CCD 블루밍/스미어(광원 세로줄) ⑦색수차+비네팅 ⑧인터레이스 콤 ⑨DV 블록 아티팩트
⑩스캔라인/REC 오버레이/타임스탬프(연출 요소)
→ ①③④만으로 룩의 70%. ⑥⑧은 비용 대비 낮음. **①~⑤,⑦은 현재 커널에 구현됨.**

## 2. 경쟁 앱 분석

- 주요 앱: Dazz Cam(종합), OldRoll(기종 코드명 네이밍), Rarevision VHS(캠코더 원류, 날짜 편집·글리치), Huji(일회용 카메라+98 스탬프), DigiCamFX(Y2K CCD 특화), DICA 99(한국, "DITTO" 필터명 직접 사용)
- 공통 패턴: 필터를 "기종"처럼 네이밍 / 타임스탬프(오렌지 폰트 국룰)+셔터음+뷰파인더 UI / 4:3 강제 + 실제 저해상도 저장 / 실시간 프리뷰가 차별점(OldRoll은 후처리라 불만)
- 유저 불만: 과한 그레인("너무 필터스러움"), 구독 강제, 워터마크, 배터리
- 적용 우선순위: ①타임스탬프 오버레이 ②저해상도 저장+4:3 ③REC 오버레이+타임코드 ④셔터음+진동 ⑤뷰파인더 프레임 UI ⑥라이트리크(보류) ⑦기종식 네이밍(문구만)
- 스킵: 다중 필름롤, 이중노출, 수동 색온도 — 필터 5종+ 될 때 재검토

## 3. iOS 촬영 근본 (우리 구현 대비 갭)

| 순위 | 항목 | 내용 |
|---|---|---|
| 1 | 사진을 AVCapturePhotoOutput으로 | 현재 비디오 프레임 JPEG 저장 → Deep Fusion/Smart HDR/12MP+ 다 놓침. photoOutput 추가 후 캡처 결과에 필터 후처리. iOS17+ zeroShutterLag |
| 2 | 세션 인터럽션 처리 | wasInterrupted/interruptionEnded/runtimeError 알림 — 전화 오면 세션 죽은 채 먹통 버그 직결. CIContext 재사용은 이미 OK |
| 3 | fps 고정 + 손떨림 보정 | activeVideoMin/MaxFrameDuration 둘 다 30fps 고정, preferredVideoStabilizationMode = .standard/.auto |
| 4 | 탭투포커스/노출 | focusPointOfInterest/exposurePointOfInterest + exposureTargetBias 슬라이더. MTKView라 좌표 변환 직접 작성 필요 (회전 주의) |
| 5 | 저조도/발열 | .custom 노출(ISO/셔터), thermalState 관찰 → serious면 필터 다운그레이드 |
| 6 | WB/마이크 모드 | 프로 모드 옵션. MicrophoneMode.voiceIsolation 등 |

흔한 실수 중 우리 해당: 비디오 프레임 사진 저장(1위), 인터럽션 미처리, fps 미고정, AVAssetWriter 비트레이트 미지정.
HDR 비디오는 끄고 SDR BGRA 유지가 필터 앱 정석 (현재 그렇게 동작 중).

## 4. Foodie/ProCCD + 디카 플래시 글로우 (2026-07-18)

- ProCCD: 40+ 필터를 카메라 기종명으로(IXUS95, U300 등), 스큐어모픽 디카 LCD UI, 앰버 7-seg 날짜스탬프(`22-02-2025 09:40 PM` 등), 플래시는 촬영 컨트롤로 존재. 4.8/5.
- Foodie: 음식 필터 + 필름 모드, 실시간 프리뷰, 피부 처리는 필터 색과학에 내장(별도 슬라이더 없음).
- 플래시 글로우 정체: 하이라이트 클리핑(플랫 화이트) + CCD 블루밍(클리핑 주변 halo) + 인카메라 NR 피부 뭉갬 + 플래시(5500K, 쿨)/실내광(3000-4000K, 웜) WB 불일치 + 역제곱 falloff(피사체만 밝음).
- 셰이더 파라미터: threshold 0.85-0.92, bloomRadius 8-20px@1080, intensity 0.3-0.6, 피부 탈채도+루마 리프트, 미드톤 웜/하이라이트 쿨, radial falloff.
- 날짜스탬프 폰트: DSEG7/Digital-7 (7-seg) 또는 도트매트릭스, 앰버(#FF8C00~#FFA500)가 정체성 핵심.
- → digicamLook 커널로 구현됨. 남은 것: DSEG7 폰트 번들, 초점 브래킷 녹색 잠금 애니메이션, 플래시 토글, 잔여매수 실감나게.

## 5. 삼성 케녹스 실기기 스펙 (2026-07-18)

- Kenox Cyber-410: 4MP CCD, 2272x1704, 35-105mm F2.9~, 영상 640x480 15fps MJPEG
- 삼성 색 성향: 채도 과장(+15~25%), 쿨톤. 캐논: 소프트+절제 채도. 소니: 베이스 ISO부터 노이즈, 대비 강함
- 룩 기여 순위: ①해상도 체인 ②JPEG 4:2:0 크로마 블리딩 ③언샤프마스크 헤일로(노이즈 뒤에 적용!) ④색튜닝 ⑤노이즈(크로마 얼룩) ⑥렌즈 열화 ⑦DR 압축
- 업샘플은 bilinear (nearest 금지)
- → digicamLook 재작성 완료(케녹스 순서), 디카 필터는 15fps 프레임스킵. 노이즈는 시간축 고정.
